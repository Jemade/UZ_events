UZ Events Serif is a reduced derivative of Source Serif 4 by Adobe.
Copyright 2014-2021 Adobe Systems Incorporated. See OFL.txt.
The modified font family was renamed to respect the reserved name Source.

Subset: Latin, Latin Extended, common punctuation, euro/trademark and selected
arrows. Dynamic text with other glyphs falls back to the CSS system serif stack.
Variable weight range: 400-700. Optical sizing and layout features retained.
Original combined WOFF2 size: 172,904 bytes. After subset: about 124 KB (28% smaller).
Names/diacritics were checked in the resulting character maps; browser visual
verification remains pending. Build-time script: scripts/subset-fonts.py.
The Python fontTools and brotli packages are needed only to regenerate fonts,
not to run the application.
